Embedding Specialist Oracle Utilities and Integration Expertise Inside Icon Water’s Team

iTANZ supplied two senior utilities consultants under an ongoing Resource as a Service model, embedded directly within Icon Water’s technology team and operating under Icon Water’s own governance, planning ceremonies and change processes.

The Problem

  • Icon Water needed deep Oracle Utilities Application Framework (OUAF) expertise and hands-on integration-migration capability that is difficult for a relatively small utility technology team to hire and retain permanently.
  • A fixed-scope delivery model would have reduced flexibility as priorities shifted between field-service transformation and integration-platform migration.
  • The utility also needed continuity of knowledge across its existing WAM, ODAMIT, Test Results, Permits and field-service integrations rather than repeatedly onboarding new vendor teams.
  • Its ageing Oracle SOA Suite integration layer required a controlled migration path that avoided a single high-risk cutover.

The Solution

  • One consultant leads the design and configuration of Oracle Fusion Field Service for water and sewerage field crews, including scheduling rules, activity types, skill and capacity profiles, and continued integration back to Oracle Utilities WAM for work-order costing and asset-condition updates.
  • A second consultant leads the migration of Icon Water’s integration layer from Oracle SOA Suite to Dell Boomi AtomSphere, re-platforming existing integrations domain by domain rather than through a big-bang replacement.
  • Existing SOA and new Boomi integration paths are run in parallel for each interface until proven, while Boomi runtime, environment, connection management, monitoring and alerting are established as part of the target operating model.
  • The embedded consultants also transfer capability to Icon Water’s internal team so future change is less dependent on scarce specialist middleware skills.
Technologies Used

Oracle Utilities Work and Asset Management (WAM) • Oracle Utilities Application Framework (OUAF) • Oracle Fusion Field Service • Oracle SOA Suite • Dell Boomi AtomSphere • Test Results and Permits system integrations

Impact We Created

Specialist skills on tap

Icon Water gained continuous access to senior Oracle Utilities and integration expertise without needing to build and retain both specialist capabilities permanently in-house.

Priorities can move

Because the consultants work inside Icon Water’s own team and governance model, priorities can shift between field-service delivery and integration migration without restarting procurement or re-scoping a new project each time.

Knowledge stays

Existing institutional knowledge of Icon Water’s WAM and integration environment is retained across phases, reducing repeated ramp-up and preserving continuity.

Decisions inside the team

Field-service configuration decisions can be made directly within the team rather than being logged with an external delivery queue.

Lower cutover risk

The SOA-to-Boomi migration is being executed interface by interface with parallel proving, reducing cutover risk and improving future maintainability.

Capability uplift

Capability uplift alongside the Boomi migration reduces future dependence on scarce Oracle SOA specialist skills.

The Conclusion

For a utility with specialist technology needs but a relatively lean internal team, RaaS provides a practical middle ground between permanent hiring and repeated fixed-scope projects. By embedding experienced consultants who already understand the environment, iTANZ gives Icon Water continuity, flexibility and direct access to the skills needed to move multiple transformation priorities forward under the utility’s own governance.
